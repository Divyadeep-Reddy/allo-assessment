# Allo Assessment

Inventory Reservation System built using Next.js, Prisma, PostgreSQL, and Supabase.

---

## Features

- View inventory products
- Warehouse stock management
- Product reservation system
- Real-time stock update
- API integration using Next.js route handlers

---

## Tech Stack

- Next.js
- TypeScript
- Prisma ORM
- PostgreSQL
- Supabase
- Vercel

---

## API Endpoints

### Get Products

/api/products

### Create Reservation

/api/reservations
